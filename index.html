How to Get an OAuth Bearer Token

Follow these quick steps using Google's OAuth Playground:

  1. Open Google OAuth 2.0 Playground in a new tab.
  2. In Step 1 on the left sidebar, scroll to YouTube Data API v3, expand it, check .../auth/youtube.readonly, and click Authorize APIs.
  3. Sign in with your Google account, then in Step 2 click Exchange authorization code for tokens. Copy the Access token and paste it below!
